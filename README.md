# ScandiBakes & Co. — курсовая работа

Интерактивная кулинарная книга, выполненная как одностраничное веб-приложение.

## Демо

Сайт: **https://anoninc111.github.io/scandibakes/**

Репозиторий: https://github.com/AnonINC111/scandibakes

QR-код для быстрого открытия: [`qr.html`](qr.html) или [`qr.png`](qr.png)

QR-код репозитория: [`qr-github.png`](qr-github.png)

## Возможности

- каталог рецептов с поиском и фильтрами;
- меню на сегодня;
- планер питания по дням недели;
- список покупок с расчётом стоимости;
- холодильник (учёт продуктов);
- добавление собственных рецептов с фото;
- «семейный код» для синхронизации данных между устройствами через localStorage.

## Технологии

HTML, CSS (Tailwind CSS), JavaScript, Font Awesome, Google Fonts.
Внешние библиотеки подключаются по CDN, база данных не требуется.

## Локальный запуск

Открыть файл `index.html` в браузере. Для корректной работы QR-страницы удобнее запустить локальный сервер:

```bash
python -m http.server 8000
```

и открыть `http://localhost:8000/`.
